# SkillSync AI 🎯

An AI-powered career development platform that analyzes your resume against **real, live job market data** and generates a personalized learning roadmap to close your skill gaps.

## 💡 What It Does

Most resume tools just give you a generic ATS score. **SkillSync AI goes further** — it connects your resume to the actual job market and tells you exactly what to learn next.

**The full flow:**
1. Upload your resume → text is extracted and parsed
2. Paste a job description → get an ATS score, matched skills, and missing skills
3. Search real, live job listings for any role (powered by Adzuna API)
4. Match your resume against the job market → see your compatibility % for each job, and the skills that are most in-demand but missing from your profile
5. Get an AI-generated, week-by-week learning roadmap (built by Gemini) targeting exactly those missing skills — complete with resources, a practice project, and LeetCode topics per week
6. Track your progress with checkboxes, streaks, and badges to stay motivated
7. (Admin) View platform-wide analytics — total users, average ATS scores, and the most common skill gaps across all users

## ✨ Features

- 🔐 **Authentication** — JWT-based auth with secure password hashing (bcrypt)
- 📄 **Resume Upload & Parsing** — PDF/DOCX text extraction
- 🎯 **ATS Analysis** — AI-powered scoring, keyword matching, and section-by-section feedback
- 🔍 **Live Job Search** — real job listings fetched via the Adzuna API
- 🧩 **Skill Matching Engine** — compares your resume against the job market, role by role
- 🗺️ **AI Learning Roadmap** — personalized, week-by-week plan generated by Google Gemini
- 🔥 **Progress Tracker** — streaks, badges, and per-task progress tracking
- 🛠️ **Admin Dashboard** — platform-wide stats and skill-gap trends
- 🎨 **Modern UI** — glassmorphism design, gradient theming, scroll-triggered animations

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas account (or local MongoDB)
- Google Gemini API key
- Adzuna API credentials
- Cloudinary account

### Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file in `backend/`:

```env
PORT=8000
MONGODB_URI=your_mongodb_connection_string
DB_NAME=skillsync
CORS_ORIGIN=http://localhost:5173

ACCESS_TOKEN_SECRET=your_secret
ACCESS_TOKEN_EXPIRY=1d
REFRESH_TOKEN_SECRET=your_secret
REFRESH_TOKEN_EXPIRY=10d

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

GEMINI_API_KEY=your_gemini_key
ADZUNA_APP_ID=your_adzuna_id
ADZUNA_APP_KEY=your_adzuna_key
```

Run the server:
```bash
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

The app will be running at `http://localhost:5173`, with the API at `http://localhost:8000`.

### Making a User Admin

To access the admin dashboard, promote an existing registered user:

```bash
cd backend
node src/scripts/makeAdmin.js your-email@example.com
```

## 🧠 How the Matching & Roadmap Logic Works

1. **ATS Analysis** extracts skills from your resume and a pasted job description using Gemini, and calculates a weighted score (section completeness + contact info + content quality + keyword match).
2. **Job Search** fetches live listings from Adzuna for a given role/location, and Gemini extracts the required skills from each job description. These are stored so they can be matched against later.
3. **Skill Matching** compares your resume's skills against every stored job (optionally filtered to a specific target role) to calculate a match percentage per job, and aggregates the most frequently missing skills across all matches.
4. **Roadmap Generation** sends those top missing skills to Gemini with a structured prompt, asking for one focused week per skill — resources, a practice project, and relevant LeetCode topics — returned as strict JSON and parsed defensively (handles malformed AI output gracefully).
5. **Progress Tracking** maintains a per-user, per-week completion record, calculates day-based streaks (increments only on consecutive calendar days, resets on a gap), and awards badges for milestones.
